# 変更内容(2026-09-30)

## 1. 震源推定の「陸側への引き寄せ」対策 (`src/epicenterEstimation.ts`)

- 震源推定側の観測点マスタから海底観測点(id 5000以上、S-net)を除外。
  検知エンジン(`shakeDetection.ts`)は S-net を検知対象外にしているため、
  着未着法で S-net が常に「未検知」として扱われ、沖合の候補にペナルティが
  加算されて推定が陸側へ押されていた。テリトリー(外部点/内部点)判定も
  S-net を含めた凸包で行われ、海側の探索範囲拡張などの補正が沖の地震で
  発動していなかった。
- 除外後の配列は元の配列ごとに `WeakMap` でキャッシュ
  (`getStationTerritories` が配列の参照でキャッシュしているため)。
- 上記により、検知点が少ない間に解が沖へ流れる問題が表面化したため、
  最初の検知点から `RANGE_PRIOR_FREE_KM`(60km)を超えて離れた候補への
  ペナルティ(`RANGE_PRIOR_WEIGHT`=0.02)を追加。検知6点まで全開、16点で0まで
  線形に弱める。
- トレードオフ: 検知点が少ない間の、遠い沖合(100km超)の地震の初期推定は
  陸寄りになる。

## 2. データ源切り替え時の検知リセット (`src/shakeDetection.ts`, `src/App.jsx`, `src/epicenterEstimation.ts`)

- リアルタイム ⇔ リプレイ・地震検知テストが切り替わったら、検知エンジン
  (観測点の履歴・イベント・広域拡大追跡・外部震源推定)と震源推定の
  キャッシュを破棄し、切り替え直後2秒間は検知を無効化する。
- `ShakeDetectionEngine.resetForSourceChange(now, suppressMs = 2000)` を追加。
  無効化期間中も値・履歴の更新(processTickのステップ1)は続ける。
- `EpicenterEstimator.reset()` を追加。
- `MapCanvas` で `realtimeSourceMode`("replay" | "test" | "live")を算出し、
  変化したtickで上記を呼ぶ。2秒は実時間(倍速リプレイでもデータ時間ではない)。
